# 💱 Currency Converter

A responsive Currency Converter web application built using HTML, CSS, and JavaScript. It provides real-time currency exchange rates using the Frankfurter API and allows users to convert between multiple international currencies with country flags.

---

## 🚀 Features

- 💱 Real-Time Currency Exchange Rates
- 🌍 Supports Multiple International Currencies
- 🚩 Automatic Country Flag Updates
- 🔄 Currency Selection (From & To)
- 💰 Convert Any Amount Instantly
- 📱 Responsive User Interface
- ⚡ Fast API Integration
- 🎨 Clean and Modern Design
